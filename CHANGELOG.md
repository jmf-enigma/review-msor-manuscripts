## [0.1.2] - 2026-08-04

### Added

- A fully synthetic mini-review demonstrating matched comparison, evidence
  calibration, the confirmation gate, and post-confirmation report prose.
- Contributor guidance for privacy-safe, fully synthetic examples and evaluations.
- Security reporting guidance for release-surface disclosure, prompt injection, and validator bypasses.
- A pull request template covering scope, privacy review, and validation.

### Changed

- Reorganized the README around an immediately visible output demonstration,
  explicit review priorities, a shorter quick start, and clearer evaluation limits.
- Extended the fail-closed release validator and manifest to cover the new public
  documentation, example, and pull request safeguards.
- Hardened release checks against hidden or inverted privacy acknowledgements,
  empty required documents, disguised data or document formats, local paths, and
  submission identifiers.

## [0.1.1] - 2026-08-04

### Changed
